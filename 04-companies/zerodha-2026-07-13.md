## Script B — Project-First (~90s)

"The most challenging thing I've built is a Performance Debug Library from scratch — a zero-config overlay for the Best Buy React Native app. Engineers and QA get real-time TTID, TTFD, TTI, FPS, memory, re-render counts, and a network waterfall, behind a feature flag with zero code changes.

The hardest part was trustworthy FPS. JS-thread counters look healthy during jank because they only measure whether JS is alive — not whether frames are painted. So I wrote native modules — Choreographer on Android, CADisplayLink on iOS — hooking the display's vsync cycle and timestamping each frame. Real drop rates, matching Xcode Instruments.

I added device-tier thresholds — a flagship iPhone and a $300 Android shouldn't share a budget — and sessions upload to Dynatrace and Sentry so regressions show in dashboards across releases.

I'm Abhav — 4.5 years across e-commerce, banking, healthcare. Outcome: 1.7s faster first-click, 12% engagement lift. That's the ownership I want to bring to Zerodha."
