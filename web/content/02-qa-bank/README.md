# Q&A Bank — how to use

**The rule that makes this valuable:** within 24h of EVERY interview, add every question
you were asked (via [00-inbox.md](../00-inbox.md)) with the answer you gave AND the better answer.

## Self-quiz

Read each `## Q:` heading → answer OUT LOUD → scroll to check. Mark shaky ones with `🔁` and revisit.

## Entry format (keep it parseable for the future app)

```markdown
## Q: <question as actually asked>

**Tags:** topic1, topic2 · **Asked at:** <company/round or "expected">

<answer in your own spoken voice>
```
